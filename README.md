# CodeForge-Solutions
Full-stack business website for CodeForge Solutions built with the MERN stack. Features a dynamic services showcase, client testimonials, animated stats, lead capture forms with Node.js backend, newsletter subscription, and a fully responsive layout — designed to convert visitors into clients.

CodeForge Solutions — Business Landing Page & Company Website (MERN)

Designed and developed the official company website for CodeForge Solutions — a digital agency offering web development, mobile apps, UI/UX design, and cloud infrastructure services.

This isn't a template — it's a fully custom, conversion-optimized business presence built from scratch using the MERN stack, crafted to attract clients and communicate credibility.

Key features shipped:
· Dynamic services showcase — Web Development, Mobile Apps, and UI/UX Design sections with structured service descriptions
· Client testimonials section — live review display with star ratings and client identity cards, built to build trust with prospects
· Stats dashboard — animated counters displaying real metrics (12+ projects, 99% satisfaction, 3x average ROI)
· Contact & lead capture — inquiry forms connected to a Node.js/Express backend for handling client consultation requests
· Team section — structured team profiles to establish agency credibility
· Newsletter subscription — integrated email capture with backend storage via MongoDB
· Fully responsive design — optimized across desktop, tablet, and mobile for a seamless user experience
· Performance-focused architecture — fast load times and scalable component structure using React.js

Built as CodeForge's live business identity — a real client-facing product, not a demo.

Stack: React.js · Node.js · Express.js · MongoDB · REST API · Responsive Design · UI/UX
